Use this data in Claude or ChatGPT

The AP score distributions on this site are also available as a free MCP server. An AI assistant can use it to look up the College Board score distribution for an AP exam, find the percentile of a score, rank exams by pass rate, and estimate a score from a composite on the seven exams with a printed worksheet. The data covers 2024, 2025 and 2026. There is no account or API key.

Claude.ai or ChatGPT. Add a custom connector with this URL.

https://ap-score-distributions-mcp.lipmichal.workers.dev/mcp

Claude Code.

claude mcp add --transport http ap-score-distributions https://ap-score-distributions-mcp.lipmichal.workers.dev/mcp
