§ 08 – Tools

Use this data in Claude or ChatGPT.

The subdomain finder on this site is also available as a free MCP server. An AI assistant can use it to list the subdomains a domain has in public certificate transparency logs, check which of them resolve over DNS, read the certificate history and summarize the attack surface. It reads public logs and DNS only. It sends no requests to the target and runs no port scans. Use it on your own assets or inside a bug bounty scope. There is no account or API key.

Claude.ai or ChatGPT. Add a custom connector with this URL.

https://subdomain-finder-mcp.lipmichal.workers.dev/mcp

Claude Code.

claude mcp add --transport http subdomain-finder https://subdomain-finder-mcp.lipmichal.workers.dev/mcp
