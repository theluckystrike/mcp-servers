Use this data in Claude or ChatGPT

The nutrition math on this site is also available as a free MCP server. An AI assistant can use it to look up USDA FoodData Central values for an ingredient, total the calories and macros of a recipe from plain ingredient lines, scale a recipe by servings, and round a label the way the FDA rules require. It uses the same USDA data as the calculator. There is no account or API key.

Claude.ai or ChatGPT. Add a custom connector with this URL.

https://recipe-nutrition-calculator-mcp.lipmichal.workers.dev/mcp

Claude Code.

claude mcp add --transport http recipe-nutrition-calculator https://recipe-nutrition-calculator-mcp.lipmichal.workers.dev/mcp
