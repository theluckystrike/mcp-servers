## Notes for the orchestrator
- Rows 1, 3, 4, 5, 7 and 8 share one root cause. The A writer framed code execution as an opt-in ("with code execution on") and called Claude.ai, Desktop and mobile a minority ("most apps"). Anthropic's help center says it is on by default for Free, Pro and Max on web, Desktop and mobile. Team and Enterprise can differ by admin setting. The live pages /can-claude/make-a-pdf/ and /can-claude/create-word-documents/ say "In Claude Desktop ... you get text only". Desktop has the same code execution, so those live pages carry the same defect (out of scope here, worth a follow-up).
- The developer-mode plan list for ChatGPT is still inconsistent across sources. Some say Plus and Pro get read/fetch-only custom servers. Our tools carry no readOnlyHint, so they may not run on Plus. The "where your plan or workspace allows" and "we haven't tested" hedges cover this. Keep them.
