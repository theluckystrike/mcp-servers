Shipped this session

  • 58 competing mirrors consolidated

    The same server existed at three URLs, each self-canonical: mcp.zovo.one/s/ (4,714 words), theluckystrike.github.io/mcp/ (525) and claudecodeguides.com/mcp/ (744). Duplicate clusters, zero consolidation. The github.io mirror now carries canonical_url -> the claudecodeguides copy (verified live), so signals land on the domain with 2,023 sitemap URLs instead of being split three ways. The page layout had canonical hardcoded, so it now honours page.canonical_url.

  • Every buy button pointed at a 404

    The generator emitted &src=... instead of ?src=..., so all 58 buy links resolved to https://mcp.zovo.one/buy/&src=... which returns 404 — the only revenue click on the whole public surface was dead. Fixed to ?src=hub., every CTA is now attributable, and selftest.py fails the build if any buy link is untagged or malformed. Verified live on GitHub Pages.

  • Hosted endpoint claim made truthful

    Every page used to promise a hosted URL even where the worker had no route. A 58-endpoint MCP handshake sweep found 46 live / 12 missing; pages, FAQ copy and JSON-LD offers are now driven by data/hosted_live.json, so the 12 local-only servers say so. Regression gate added to selftest.py.

  • claudecodeguides.com deploy unblocked

    The CI deploy had been failing for days with Cloudflare 'Authentication error 10000': the repo secret was stale. Rotated CLOUDFLARE_API_TOKEN / CLOUDFLARE_ACCOUNT_ID to the working credentials, excluded vendor+bundle from the Jekyll build, pushed the hub + 10 guides — and the deploy went green: https://claudecodeguides.com/mcp/ answers 200, its sitemap.xml grew from 1,953 to 2,023 URLs, and IndexNow accepted all 71 /mcp/ URLs. (Correction: 1,953 was the sitemap size, not an indexation count — that domain is not in our GSC properties, so its indexation is unmeasured.)

    Real browser headers → 303 → checkout.stripe.com/c/pay/cs_live_…. The rail was never broken; the earlier “404 on POST” reading was the bot guard answering a scripted probe.
