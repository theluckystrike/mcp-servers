# remote - hosted MCP endpoints

One Cloudflare Worker serving the tool sets of `servers/time-tracker`,
`servers/price-tracker` and `servers/invoice` over MCP streamable HTTP at
https://mcp.zovo.one/mcp/<name> . `mcp-billing` keeps the rest of the domain; this
worker is mounted on the route pattern `mcp.zovo.one/mcp*`.

    npm run vendor   # regenerate src/vendor/ from servers/<name>/src
    npm run deploy   # vendor + wrangler deploy

`src/vendor/` is generated by `build-vendor.mjs` and checked in. Regenerate it after any
change to the stdio servers' sources, or the hosted endpoints drift from the packages.

Full design, verification transcript and limitations: ../docs/REMOTE_RESULT.md
