## The one finding that reorders everything

- `mcp.zovo.one/sitemap.xml` — 299 URLs submitted, **0 indexed**, last download 2026-10-26.
- URL Inspection on `https://mcp.zovo.one/s/invoice` → `verdict NEUTRAL`,

With zero indexed pages there is no organic traffic, and with no traffic the catalogue, the pricing
and the checkout cannot matter. Rails are not the constraint. Traffic is.

## The rail was never broken

Earlier sessions recorded "POST /s/invoice → 404, checkout dead". That was wrong. Evidence:

```
curl -sI -X POST https://mcp.zovo.one/buy/invoice?src=audit.probe        # bare curl
-> 303 location: https://mcp.zovo.one/s/invoice  x-mcp-buy: scripted-ua-no-session

# with a real browser header set (Origin, Sec-Fetch-Mode: navigate, Sec-Fetch-Dest: document,
# Chrome UA) and the order_token the form itself emits:
-> 303 location: https://checkout.stripe.com/c/pay/cs_live_a1VJlZpiXVnpXnBu308ioIdLjKhR5KqcEfr1MOrFwAu6m117l6VkXpPna
   time 1.22 s
```

`isCheckoutIntent()` (billing/src/index.js:1146) requires `origin`, `sec-fetch-mode: navigate`,
`sec-fetch-dest: document`, urlencoded body, `intent=checkout` and a minted `order_token`
(`^\d{13}\.<uuid4>$`, ≤ max age). A scripted probe fails the guard by design and is bounced to the
product page. A human never sees that. **Stripe is live.**

## The money math

ARP ~ $19 single / $39 bundle. To clear $1,000/month at 2% conversion from traffic you need ~2,600
sessions/month. At the current 38 impressions/7d and 0 indexed pages, the traffic term is 0, so revenue
is 0 regardless of price, copy, or rail. The only two levers with a non-zero multiplier today:

1. **Indexation** (0 → n). One dofollow link from an already-indexed page is worth more than 58 new
   pages on a domain Google has not discovered.
2. **npm** (0 → 58 packages). The registry the MCP directory reads, and the corpus LLMs are trained on.
   Five minutes of `npm login`.

# Session 2 - distribution unblocked (02:00-03:20Z)

## What was actually broken, and is now fixed

1. **Every buy button on every public page pointed at a 404.**
   `build_hub.py` emitted `%(buy)s&src=...`. `https://mcp.zovo.one/buy/invoice&src=x` returns **404**
   (`...?src=x` returns 200). So the single revenue click on 58 pages was dead on arrival.
   Fixed to `?src=hub.<slug>`; all 59 pages now carry attribution; `selftest.py` fails the build if any
   buy link is untagged or malformed. Verified live: `/mcp/invoice/` on GitHub Pages serves
   `buy/invoice?src=hub.invoice`.

2. **claudecodeguides.com could not deploy at all.** The repo secret `CLOUDFLARE_API_TOKEN` was stale;
   every run died at `deploy-cloudflare` with `Authentication error [code: 10000]` after ~50 minutes of
   building. Rotated both secrets to the working credentials already on this Mac, excluded
   `vendor/` and `node_modules/` from the Jekyll build, pushed the hub + 10 guides.
   **Result: run 40620291081 went fully green** - build, deploy-cloudflare, deploy (GitHub Pages) and
   indexnow all success.
   - https://claudecodeguides.com/mcp/ -> 200
   - /mcp/invoice/ -> 200, /mcp/guides/ -> 200, /mcp/index.json -> 200
   - sitemap.xml grew from 1,953 to **2,023** URLs (the 70 /mcp/ pages are in it)
   - IndexNow accepted all **71** /mcp/ URLs (key `c4ded4558ba249bbbd828bbfd67ebe80`, key file 200)

3. **12 of 58 pages promised a hosted endpoint that does not exist.** A real MCP `initialize` +
   `tools/list` sweep found **46/58 live, 12 missing** (`budget`, `payroll`, `receipts`, `office-suite`,
   `tax-calc`, `loan-calculator`, `pomodoro`, `hourly-rate`, `duplicate-invoice-check`, ...). The worker
   source's `HOSTED_SERVERS` set contains exactly the same 46, so this is deliberate inventory, not a
   stale deploy. Pages, FAQ and JSON-LD text now come from measured `data/hosted_live.json`: the 12 say
   "not open for this server yet", the 46 say "the other 46 servers are already hosted".

4. **The hosted instruction led straight into a 401.** The bare `https://mcp.zovo.one/mcp/<id>` lists
   tools but answers `tools/call` with `401 unauthorized`. Install copy on all 46 pages now starts at
   `https://mcp.zovo.one/mcp/connect` and gives the tokenised URL `<...>/t/<token>`.
