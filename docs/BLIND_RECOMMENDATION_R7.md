# Blind Recommendation — Round 7 (S130, 2026-09-21) — TRUE BLIND PASS

Method: unprimed buyer-intent web searches, one search per question (18 total), real
search-result URLs only. Estate recommendation pass (estate-primed, ledger-mapped) was
run separately earlier the same day; this pass measures organic retrieval.

## Scores

- **12 / 18** questions yielded a specific, credible MCP-server recommendation from
  organic top results.
- 6/18 returned only tutorials, aggregators, or nothing useful (q6 quotes/estimates,
  q10 spreadsheet-from-chat, q14 delivery schedule/work order, q16 no-install usage,
  q17 small-business accounting roundup, q18 paid MCP discovery) — these are the
  estate's whitespace.
- **Estate organic appearance: 1/18** — `github.com/theluckystrike/mcp-expense-tracker`
  surfaced on q3 (expenses/mileage). That is the estate's only organic retrieval this round.

## Notable

- Payment/billing space (q15, q18) dominated by Chargebee, Recurly, aggregator lists —
  no indie per-server checkout pages ranked.
- Accounting roundups (q17) list light.inc and generic finance MCPs; office-suite
  servers did not rank.
- q1 (invoice PDF) surfaced tutorials, not installable servers — buyers can't find
  one-click answers.
- Estate recommendation pass for comparison: 18/18 answered, 92% self-score
  (earlier commit d9a460cf) — the gap between 18/18 primed and 12/18 + 1 organic
  retrieval is the distribution KPI signal for next sprint.
